# 独立换装接口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增独立异步换装任务：一次上传多张商品图和多张模特图，LangGraph invoke 一次，节点内全组合，每次 `images.edit` 为 1 模特图 + 1 商品图。

**Architecture:** 与印花任务并行的 `POST /try-on-jobs`。`ingest_try_on` 校验列表；`build_try_on_graph` 编译 `ingest → try_on`；`try_on` 按商品图×模特图调用现有 `ImageEditor.edit([model, product], TRY_ON_PROMPT)`。`JobStore` 类复用，应用内两个实例。

**Tech Stack:** FastAPI, LangGraph, OpenAI `images.edit`, pytest

**Spec:** `docs/superpowers/specs/2026-10-14-try-on-design.md`

## Global Constraints

- 印花 `POST /jobs` 行为不变
- 每一次 edit 参考图顺序为 `[模特图, 商品图]`
- 某一对失败则整次任务失败
- 图片后缀仅 `.png` / `.jpg` / `.jpeg` / `.webp`
- 输出文件名 `{product_name}__{model_name}.png`
- 单元测试用假 editor，真实生图标 `integration`

```python
def ingest_try_on(products: list[Path], models: list[Path]) -> dict:
    if not products:
        raise IngestError("at least one product photo is required")
    if not models:
        raise IngestError("at least one model photo is required")
    for product in products:
        _require_image(product, "product")
    for model in models:
        _require_image(model, "model")
    return {
        "products": [{"name": product.stem, "photo_path": product} for product in products],
        "models": [{"name": model.stem, "photo_path": model} for model in models],
    }
```

```python
def test_create_try_on_job_generates_one_image_per_pair(tmp_path: Path) -> None:
    client = _client(tmp_path)
    response = client.post(
        "/try-on-jobs",
        files=[
            ("products", ("red.png", MINIMAL_PNG, "image/png")),
            ("products", ("blue.png", MINIMAL_PNG, "image/png")),
            ("models", ("front.png", MINIMAL_PNG, "image/png")),
            ("models", ("side.png", MINIMAL_PNG, "image/png")),
        ],
    )
    assert response.status_code == 202
    job_id = response.json()["id"]

        ("red", "front"),
        ("red", "side"),
        ("blue", "front"),
        ("blue", "side"),
    ]
    first = client.get(body["try_on_images"][0]["url"])
    assert first.status_code == 200
    assert first.content == MINIMAL_PNG
```
